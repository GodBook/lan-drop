# Android 发布签名

仓库不保存发布密钥或密码。旧版 `landrop.keystore` 已经公开，不能再用于正式分发；换用新密钥后，使用旧签名安装的用户需要先卸载旧版再安装新版。

## 生成新密钥

在受控设备上执行以下命令，并将生成的密钥纳入独立的加密备份：

```shell
keytool -genkeypair -v -keystore landrop-release.keystore -alias landrop-release -keyalg RSA -keysize 4096 -validity 10000
```

不要把生成的密钥复制到仓库的 `android/app/` 目录。

## 配置 GitHub Actions

在仓库的 Actions secrets 中配置：

- `ANDROID_KEYSTORE_BASE64`：新密钥文件的单行 Base64 内容
- `ANDROID_KEYSTORE_PASSWORD`：密钥库密码
- `ANDROID_KEY_ALIAS`：密钥别名
- `ANDROID_KEY_PASSWORD`：私钥密码

Linux/macOS 可用 `base64 < landrop-release.keystore | tr -d '\n'` 生成单行内容；PowerShell 可用 `[Convert]::ToBase64String([IO.File]::ReadAllBytes('landrop-release.keystore'))`。

CI 只在任务运行期间把密钥解码到 `RUNNER_TEMP`，构建完成后立即删除。缺少任何一项配置时，release 构建会明确失败；不需要签名配置即可执行 debug 构建和单元测试。
